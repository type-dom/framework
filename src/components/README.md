## TypeDom 框架公共组件

### 1. teleport 指向组件

    Teleport组件的主要功能是在组件树之外的其他位置渲染其子节点。
    它主要用于解决某些情况下，由于布局或DOM结构限制，无法直接在组件树内部渲染元素的问题。
    在实际使用中，用户可以创建一个Teleport组件，并指定to属性来确定子节点应该渲染到的DOM元素。
    在组件渲染时，将子节点移动到to指定的位置，而不是在当前组件的挂载点。
    这使得开发者可以在不改变组件结构的情况下，灵活控制元素的渲染位置。

### 4.SimpleComponent 组件

    基于原生Html DOM 元素的组件，封装了原生Html DOM 元素的属性、事件、样式等。
    简单组件都直接调用 slotChild方法，将 params.slot添加为子节点。
